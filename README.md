Дисплей 3,3 - 5 вольт питание. На плате распаян стабилизатор напряжения или транзистор который мешает получать адрес.
При отключении GND адрес выдает по i2c если не убирать в обвязке транзистор и не подпаивать питание напрямую.
После отпаивания и подключении питания напрямую, дисплей становится только 3,3 вольта без защиты но при этом начинает работать.
Дисплей имеет адрес 0x3f
Контроллер st7567s на который нет нужного алгоритма например в библиотеке u8g2. В этой библиотеке версия только для SPI.
